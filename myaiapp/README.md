# AI Atelier

سبع صفحات HTML مستقلة للدردشة والصور والأغاني والبريمبتات، بتصميم موحد وفخم.

الصفحات داخل حزمة النشر: `index.html`, `chat.html`, `qwen.html`, `glm.html`, `prompts.html`, `images.html`, `songs.html`.

تستخدم الواجهة:
- `https://proxy-ai.img-api.workers.dev/v1/chat/completions`
- `https://thorfin-synt-img.img-api.workers.dev`
- `https://thorfin-music.img-api.workers.dev`

النشر يتم تلقائياً عبر GitHub Pages من الملف `.github/workflows/ai-atelier-pages.yml`.
